# PyQt5 Web Browser

A lightweight, custom-built web browser using PyQt5 and QtWebEngine. Features include tabbed browsing, built-in ad blocking, download management, and intuitive navigation controls.

## Features

- **Tabbed Browsing:** Open, close, and switch between multiple browser tabs.
- **Ad Blocker:** Blocks common advertising and tracking domains for cleaner browsing.
- **Navigation Toolbar:** Back, forward, refresh, home buttons with keyboard shortcuts.
- **URL Bar:** Enter and navigate URLs with auto-correction for common protocols.
- **Download Manager:** Save files with prompt dialogues and quick access to downloads folder.
- **Custom Status Bar:** Displays helpful messages and information.
- **Keyboard Shortcuts:** Includes Ctrl+T for new tab, Ctrl+R for refresh, Esc to close browser.

## Requirements

- Python 3.7+  
- PyQt5  
- PyQtWebEngine

## Installation

1. Clone the repo:  
```bash
git clone https://github.com/IchigoSolos69/Web-Browser.git
cd Web-Browser
```

2. Install dependencies:  
```bash
pip install PyQt5 PyQtWebEngine
```

## Usage

Run the browser with:  
```bash
python Web-Browser.py
```

- Use the toolbar buttons or keyboard shortcuts to navigate.  
- Add new tabs with Ctrl+T.  
- Close the browser with Esc.  
- Enter URLs directly into the address bar.
